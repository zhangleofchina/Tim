# WorkBuddy 链路验证

这个目录由 WorkBuddy 在本机生成并提交，用来验证 GitHub 通道是否可用。

## 结论：本地提交没问题，推送卡在凭据

- 本地 git 提交：正常
- HTTPS 克隆：正常（实测通过）
- 推送：需要 PAT 或 SSH 密钥，当前机器两者都没有

## 三个通道的实际能力

| 通道 | 读 | 写 | 依赖本机网络 |
|---|---|---|---|
| 本机 git（HTTPS） | 可 | 需 PAT | 是 |
| WorkBuddy GitHub 连接器 | 可 | 不可（只读授权） | 否 |
| 网页登录 | 打不开 | 打不开 | 是 |
